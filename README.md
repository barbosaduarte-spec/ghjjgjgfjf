# ⚡ Neon Reflex

Jogo web de reflexos e precisão com ranking global em tempo real.

## Tecnologias
- HTML5, CSS3 e JavaScript (ES Modules)
- Firebase Firestore (Banco de Dados NoSQL em nuvem)
- GitHub Pages (Hospedagem gratuita)

## Como rodar localmente
Basta abrir o arquivo `index.html` usando uma extensão como o **Live Server** no VS Code.
